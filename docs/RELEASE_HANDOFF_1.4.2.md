# CloudArc 1.4.2 — нативный семантический поиск больше не привязан к версии Python

Дата: 12.09.2026. Автор изменений: Вячеслав Бочкарёв.

## Что было сломано

`core/semantic.py` отказывался работать с нативным модулем ViBo на любом
интерпретаторе, кроме CPython 3.11:

    if sys.version_info[:2] != (3, 11):
        reason = "native ViBo package requires CPython 3.11"

Это была не проверка возможностей, а прокси для «наша сборка — cp311». Практические
последствия: на venv с Python 3.12 (например, на Крабе) нативный модуль было нельзя
использовать даже при наличии сборки под 3.12, а семантический поиск молча падал в
лексический с невнятной причиной. Дополнительно выяснилось, что контракт
`cloudarc.native-semantic-v1` не реализовывала ни одна сборка ViBo — то есть
семантический режим не работал нигде, а гейт это маскировал.

## Что изменено

1. **Версионный гейт убран.** Проверка теперь настоящая: пробуем импортировать модуль
   и требуем явное объявление capability (`semantic_search.supported`,
   `api_version`, `index_schema_versions`, `search_function`).
2. **Диагностика стала действенной.** Если сборки под текущий интерпретатор нет,
   CloudArc сообщает, какие сборки рядом есть и какую нужно:
   `vibo_archive не собран под cpython-312 (в /opt/vibo есть сборки:
   cpython-311-x86_64-linux-gnu); нужна сборка под cpython-312`.
   Отдельно распознаётся «расширение собрано под другой CPython» (PyInit/ELF/file too short).
3. **Проба не обманывается кэшем `sys.modules`**: если путь к модулю задан явно,
   модуль грузится именно оттуда.
4. **Индекс перестал врать**: при упаковке `semantic.status` пишется `ready` с
   `model_id`, `dimensions`, `metric`, `index_ref` — если нативный движок реально
   доступен (раньше всегда было `unavailable`, даже когда поиск работал).
   Для этого добавлена функция `cloudarc_semantic_descriptor()` в контракт
   (`descriptor_function`) и проброс настроек `native` из конфига в `pack`.
5. **10 новых регрессионных тестов** (`tests/test_native_capability.py`): отсутствие
   версионного гейта, согласование capability, диагностика сборок, честный откат в
   лексику без бэкенда. Всего в наборе 162 теста + 17 подтестов.

## Сторона ViBo (в этом же релизе)

- `vibo_cloudarc.py` — открытый исполнитель, публикующий контракт
  `cloudarc.native-semantic-v1`: эмбеддинги через ViBo-эмбеддер/fastembed, честный
  откат на лемматизацию с другим `model_id`;
- набор защищённого ядра, собранный Nuitka под **cpython-312** (core, crypto,
  semantic, embedder, navigator, storage, analytics) — чтобы нативный модуль
  работал и на Python 3.12.

## Проверено

- `cloudarc runtime --json` под 3.12: `semantic_available: true`,
  `api_version: cloudarc.native-semantic-v1`, `model_ids: [fastembed:multilingual-default]`.
- `cloudarc search <архив> "..." --mode semantic --json`: `mode_used: semantic`,
  `fallback_reason: null`, результаты с оценками и цитатами; индекс `status: ready`,
  `dimensions: 384`, `index_ref: sidecar`.
- Тесты: 162 passed, 17 subtests passed.

## Совместимость

Формат архивов не менялся (format v1/v2, index v2). Архивы, упакованные более
ранними версиями, читаются; индекс старого образца просто не объявляет семантику
`ready` — режим по-прежнему можно запросить, и он будет обслужен нативным
исполнителем, если тот доступен.
